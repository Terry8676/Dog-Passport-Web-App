# Pet Care Passport

A web app that helps pet owners and sitters stay aligned during a stay.
This MVP only covers the medication log so far: owners add a dog's medication, and sitters
record whether each dose was given, skipped, or unable to give, with timestamps.

**Live app:** https://pet-passport-3rbo.onrender.com
(Since my subscription is free, the deployed website will sleep when idle, so the first load can take about a minute.)

## Tech stack
- Backend: Node.js + Express
- Frontend: HTML, CSS, JavaScript 
- Database: PostgreSQL on Neon
- Hosting: Render
- CI: GitHub
